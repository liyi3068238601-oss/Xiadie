# ADR-0050：上下文专项总验收与协议冻结

- 状态：Accepted
- 日期：2026-07-20

## 决策

CTX.7 冻结以下稳定边界：

- SQLite schema 45；
- `context-budget-v1`；
- `conversation-summary-v1`；
- `context-package-v1`；
- `conversation-history-index-v1`；
- `conversation-history-score-v1-shadow`；
- `context-acceptance-v1` 合成验收输出。

普通聊天的跨会话自动召回继续保持 shadow。固定显式回忆集全量通过并不足以证明普通问答不会误召回；没有用户明确授权时，不读取真实聊天正文做校准，也不移除 shadow 后缀。

Token 估算器继续采用无需外部 tokenizer 的保守实现。当前没有经用户明确提供的 Provider usage 样本，因此误差报告记录“未实测”，不编造误差数字、不放宽窗口限制。验收脚本允许用户以后显式提供本地样本文件，输出只保留聚合误差，不回显正文。

N17 采用最小安全修复：知识检索轮次中，只有当前用户消息作为唯一证据、且已经通过观察协议原文 grounding 的 `conversation` 候选可以写入长期记忆。知识正文、助手推断、`knowledge_reference`、`shared_lookup` 和混合证据继续拒绝。

## 理由

遐蝶的核心是陪伴与聊天连续性。完全阻断知识轮次中的用户亲口偏好会造成明显失忆感；放宽到助手或资料正文则会污染相处记忆。当前规则在两者之间保持可验证边界。

协议冻结表示后续修改必须使用新协议版本和 ADR；不表示召回质量已经永久完成。普通自动召回只有在新增不含私密正文的固定普通查询集、或用户明确授权的聚合校准证据通过后，才能另立 ADR 升级。

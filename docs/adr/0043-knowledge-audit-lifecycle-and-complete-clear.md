# ADR-0043：知识审计保留、引用完整性与完整清除

- 状态：接受
- 日期：2026-07-19
- 策略版本：`knowledge-audit-retention-v1`

## 决策

知识审计采用分层保留：recall decision 保留 90 天，终态 transmission grant 保留 30 天，完整 retrieval 元数据保留 180 天。Citation 不按固定天数独立清除，而是与承载它的助手消息同生命周期。

超过 180 天的 retrieval 若没有 citation，可以物理删除；若仍被可见消息引用，则只最小化查询指纹、触发原因和计数等检索元数据，并保留最小 retrieval 锚点。这样既减少长期审计元数据，又不会因外键级联让历史回答的引用消失。

文档、切片、全文索引和向量索引不属于审计清理对象。定期审计清理不得改变当前知识可搜索性。

## Collection 策略

每个 collection 保存新普通文档的默认远传策略及 revision。用户可以只修改未来默认值，也可以原子应用到已有文档。批量应用遇到敏感文档允许远传或删除中文档时整批回滚，不产生部分成功；被修改文档的未完成授权立即撤销。敏感文档导入始终强制 `local_only`，不会继承宽松默认值。

## 完整清除

完整清除要求固定确认文本 `CLEAR_ALL_KNOWLEDGE`。确认后在同一数据库事务中：

1. 所有文档立即退出全文与向量召回；
2. 为每份文档建立或恢复可重试删除任务；
3. 清除 citation、retrieval、grant、recall decision 和模式变更派生审计；
4. 由已有删除 worker 物理清理遐蝶应用数据目录中的原文副本、解析产物、切片和索引。

应用外的用户原文件和备份永远不在清除范围内。单文档普通删除仍保留历史引用定位；只有用户明确执行“完整清除”才会清除全部派生引用。

## 导出与备份边界

`knowledge-export-manifest-v1` 只导出 collection、文档名称、内容指纹、状态、策略和版本等元数据，不包含知识正文、切片、向量、文件路径、模型授权 token 或 API key。正文不会被默认导出。

## 可观测性

管理接口公开保留策略、各类无正文审计数量和 `knowledge_memory_write_blocked` 的累计隔离计数。检索记录公开 `search_protocol_version` 与 `audit_state`；不公开查询正文或被隔离候选正文。

# ADR-0068：CIE 原生图片能力证据与单轮字节生命周期

- 状态：已接受并随 CIE.3 独立 Review 冻结
- 日期：2026-07-29
- 协议：`vision-probe-v1`、`cie-image-attachment-v1`
- Schema：81

## 决策

模型只有在当前 `provider_id + model + provider_location_revision` 组合通过真实 1×1 图片探针后，才获得 `vision` 能力。模型名称、供应商宣传或文本模型成功响应均不构成图片能力证据。探针只持久化状态、协议、错误码、响应摘要和时间，不保存图片或响应正文。

PNG/JPEG 图片在本地验证签名、声明 MIME、尺寸、像素、字节和 SHA-256 后进入一小时临时区。单张上限 5 MiB、单轮最多 4 张、单轮总计 10 MiB/1600 万像素、单边最多 4096。远程或位置未知的 Provider 必须按本轮显示目标并取得一次确认；请求同时携带 Provider、模型和位置版本快照，任一变化均在消息写入前失败。积累窗口还必须让每条图片消息携带 `local_image` 或 `remote_image_once` 范围。

图片 data URL 只在 CTX 完成文本组装后加入最后一条用户消息，并只交给当前聊天 Provider。用户消息、Memory、Knowledge、KIG、观察器和日志只看到用户文字及非正文元数据。用户消息与附件绑定提交后，数据库中的临时路径在同一事务清空，随后立即删除原始文件；历史仅保留文件名、MIME、字节、尺寸和哈希，不能重放原图或据此重新生成。

## 降级与诚实性

- 能力未知时前端可主动运行最小探针；探针失败、模型不支持或用户拒绝时明确告知，绝不把图片当作已看见。
- CIE.3 不引入本地 OCR 依赖；明确拒绝是本阶段的合规回退。OCR/描述候选若以后加入，必须保持本地处理并另行验证准确性。
- 当前配置的 `deepseek/deepseek-v4-flash` 实测返回 HTTP 400，记录为 `unsupported`；这是正确的能力结果，不是 CIE.3 失败。切换到视觉模型后需要对新组合重新探测。
- 临时文件 TTL 与启动清理只保证本机单进程生命周期；多进程共享存储不在当前承诺内。

## 回滚

关闭唯一的 `cie_enabled` 总门会在上传和聊天写入前拒绝原生图片，同时保留既有文本附件路径。Schema 81 的元数据列和能力证据表可留存；回滚不需要恢复或转换图片正文，因为正文从未成为持久数据。

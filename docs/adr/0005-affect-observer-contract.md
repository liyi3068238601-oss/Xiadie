# ADR-0005：旁观观察器输出协议与信任边界

- 状态：Accepted
- 日期：2026-07-15
- 决策者：项目所有者、Codex
- 关联计划：`docs/AFFECT_AND_RELATIONSHIP_SYSTEM_PLAN.md` 阶段 2.1

## 背景

旁观模型需要读取完整的一轮用户与助手消息，判断短期心境和极小的长期关系变化。模型输出本身不可信：它可能被对话中的提示注入影响、返回非法 JSON、伪造证据、输出极端数值，或把普通技术报错误判为关系破坏。

在接入任何真实模型前，必须先建立独立、确定、可测试的协议层。

## 决策

- 唯一协议版本为 `affect-observer-v1`，由严格 Pydantic 模型生成 JSON Schema。
- 禁止额外字段、未知枚举、非有限数和缺失字段。
- 对话正文作为标记为 `untrusted_conversation_data` 的 JSON 数据传入，不拼进 system 指令。
- 所有非零 delta 必须附带逐字证据，程序核对证据是否存在于声明的用户或助手原文。
- 模型值通过 schema 后仍按计划书单轮上限二次限幅。
- 低置信度只允许有限降低 contact_need 和极小改变 immersion，长期关系变化全部归零。
- 正向 trust 需要 `positive_reliability` 依据；负向 trust 需要 `explicit_boundary_violation`，并且用户证据中必须存在明确人际边界表达。
- 校验结果只是候选 delta。本阶段不提供数据库写入、状态应用、记忆修改、权限改变或主动发送路径。
- 校验错误只返回稳定错误码和不含对话正文的说明，原始敏感内容不得进入普通错误日志。

## 后果

- 模型供应商、模型能力和提示词可以替换，但状态安全边界保持不变。
- 观察器不能仅凭自我声明改变 trust，也不能用伪造引文作为证据。
- 后续接模型时必须显式处理拒绝、候选、恢复和审计，不能直接把反序列化结果写入状态。
- 对边界语义的本地线索过滤会保持保守，可能漏掉少数隐含表达；漏掉意味着不改变 trust，而不是猜测。

## 回滚

停用观察器调用即可完全回到确定性 fallback 引擎。本 ADR 对现有数据库没有迁移或写入影响。

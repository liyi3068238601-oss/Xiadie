# ADR-0049：对话连续性独立控制与无正文诊断

- 状态：Accepted
- 日期：2026-07-20
- 阶段：CTX.6
- Schema：45

## 决策

1. “长期记忆”“参考过往聊天”和“会话摘要注入”是三个独立控制面。关闭任一项都不删除原始聊天，也不暗中修改另外两项。
2. “参考过往聊天”默认开启，但只允许用户明确问起过去时注入；普通聊天继续 shadow，不在 CTX.6 把未校准权重投入正式陪伴对话。
3. 摘要继续自动生成。用户关闭的是摘要注入，不是原始消息保存或后台派生；手动重建期间保留上一份有效摘要，成功后再替换。
4. 用户可单独删除派生摘要。该操作保留全部原始消息，并显式刷新历史会话索引中的摘要字段。
5. schema 45 只保存上下文预算、来源类型计数、裁剪原因、协议和摘要 revision；不保存消息、摘要、记忆、知识、查询或模型输出正文。
6. 普通聊天移除“本轮参考了几条记忆/资料”等技术提示。控制和诊断仅位于记忆设置中的折叠高级区域，以保持陪伴与聊天体验。
7. 摘要属于派生连续性资料，不得冒充用户原话或逐字引用；明确历史回忆携带真实会话标题、时间和 locator。

## 删除与导出语义

- 永久删除会话：原始消息、派生摘要、历史索引和会话级诊断按外键/触发器同步失效。
- 删除派生摘要：仅删除 summary run/revision/event，原始消息和长期记忆不变。
- 重建摘要：创建新的 full run；旧 active 摘要在新结果通过前继续有效。
- 数据导出：原始对话与派生数据必须分区标记，不能把摘要包装成原始发言；无正文诊断只导出计数和协议字段。

## Review 取舍

CTX.5 strict review 的优先级、预算降级、来源完整性和无正文诊断建议全部采纳。真实用户数据默认校准与立即退出 shadow 不采纳：CTX.7 仅使用合成数据或用户明确授权的数据，普通自动召回在质量门通过前继续 shadow。

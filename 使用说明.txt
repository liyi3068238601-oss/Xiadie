========================================================
  遐蝶 · Windows 桌面 AI 伴侣 Agent  —  使用说明
========================================================

这是一个能在你 Windows 电脑上运行的桌面 AI 伴侣：
一个 Live2D 桌宠浮在桌面上，点击它打开主窗口，可以聊天、记忆、
建任务、配置多家 AI 模型。桌宠会跟着聊天内容切换表情。


--------------------------------------------------------
一、最快上手：一键打包安装（推荐）
--------------------------------------------------------

1) 把整个「live2D桌宠」文件夹拷到你的 Windows 电脑（任意位置，
   比如 D:\live2D桌宠）。

2) 双击文件夹里的：   一键打包安装.bat

3) 剩下的它自动完成：
   - 自动检查 / 安装 Node.js 和 Python（缺了会用 winget 装，
     可能弹一次 UAC 授权，点“是”）；
   - 构建前端、把后端打包成独立程序、生成安装器；
   - 自动弹出安装向导，按“下一步”装完即可。

   首次运行需要几分钟（要下载一些依赖，请保持联网、耐心等待）。

4) 装完后：桌面 / 开始菜单会出现「遐蝶」。启动后桌宠出现在
   桌面右上角，点击桌宠即可打开主窗口开始使用。

   ★ 安装后运行时不需要 Python / Node，后端已经打包进程序里。

如果双击后中途报错（比如没有 winget、或自动装依赖失败），
窗口里会有中文提示，按提示手动装好 Node（LTS）和
Python 3.12（安装时勾选 Add Python to PATH）后，再双击一次即可。


--------------------------------------------------------
二、怎么用这个应用
--------------------------------------------------------

【桌宠】
  - 浮在桌面右上角，透明、置顶。
  - 单击桌宠 = 打开 / 聚焦主窗口。
  - 按住拖动 = 把桌宠移到桌面任意位置。
  - 右键桌宠 = 菜单（打开主窗口 / 隐藏 / 重置位置 / 退出）。
  - 系统托盘也有图标，可随时打开主窗口或退出。
  - 桌宠会随聊天切换表情（开心 / 星星眼 / 思考歪头等），
    空闲时也会自己轻微换表情。

【主窗口】三栏布局
  - 左侧：新建对话、会话列表、功能导航（对话/任务/记忆/文件/设置）。
  - 中间：聊天区。输入消息，回车发送，回复是流式逐字出现。
  - 右侧：遐蝶状态（当前心情、最近记忆、今日任务、模型能力）。

【配置 AI 模型】★ 重要
  首次启动用的是“内置演示”模型，只会返回固定的演示文字，
  不是真的 AI。要获得真实回复，请：
    1. 主窗口左侧点「设置」→「模型 API」。
    2. 选一个供应商（DeepSeek / OpenAI / 智谱GLM / 通义千问 /
       Kimi / OpenRouter / 硅基流动 / Ollama / 自定义）。
    3. 点「配置」，填入该供应商的 Base URL 和 API Key。
    4. 点「连接测试」，通过后在顶部「当前模型」选中它，点「设为当前」。
  之后聊天就是真实模型的回复了。
  （API Key 只存在你本机，不会明文显示、不会上传。）

【记忆】
  遐蝶会记住你的偏好和项目背景；聊天中说“记住…”会自动存一条。
  「记忆与关系」页可查看 / 编辑 / 删除 / 启用停用每条记忆。

【任务】
  「今日任务」页可新建任务；也能从对话里生成。
  支持待办 / 进行中 / 已完成状态切换。

【数据存哪】
  你的会话 / 记忆 / 任务 / 设置都存在本机：
    %APPDATA%\遐蝶\data\   （即 C:\Users\你的用户名\AppData\Roaming\遐蝶\data）
  不会上传到云端。


--------------------------------------------------------
三、开发模式（可选，想改代码 / 不打包直接跑时用）
--------------------------------------------------------

需要 Node ≥ 18 和 Python 3.10–3.12。开三个终端：

  终端1（后端）：
    cd backend
    python -m venv .venv
    .venv\Scripts\pip install -r requirements.txt
    .venv\Scripts\python run.py

  终端2（前端）：
    cd frontend
    npm install
    npm run dev

  终端3（桌面壳）：
    cd desktop
    npm install
    npm start

  启动后桌宠出现在桌面，点击打开主窗口。


--------------------------------------------------------
四、常见问题
--------------------------------------------------------

Q: 首次运行提示“Windows 已保护你的电脑 / SmartScreen”？
A: 因为安装器没做代码签名。点“更多信息”→“仍要运行”即可。
   （自用无妨；正式对外发布才需要买代码签名证书。）

Q: 桌宠显示成一只蝴蝶 + “未找到 Live2D 模型”？
A: 说明模型文件没打包进去。确认 frontend\public\models\xiadie\
   里有 Xiadie.model3.json 等文件后重新打包。本压缩包已内置模型。

Q: 后端起不来 / 聊天一直转圈？
A: 后端固定用本机 127.0.0.1:8756 端口。若被占用，
   改 backend\run_frozen.py 和 desktop\main.js 里的端口后重打。
   排障时可把 backend\xiadie-backend.spec 里 console=False 改成 True
   重新打包，能看到后端日志窗口。

Q: 想让别人也用 / 想上架分发？
A: 见下面“重要提醒”。当前内置模型不允许再分发，需先替换模型。

六、目录结构速览
--------------------------------------------------------

  一键打包安装.bat      ← 双击这个（Windows 一键打包+安装）
  build-windows.ps1     ← 纯构建脚本（一键脚本内部会调用）

  frontend/             ← React 前端（主窗口 + 桌宠页 + Live2D 模型）
  desktop/              ← Electron 桌面壳（打包配置在 electron-builder.yml）
  demo/                 ← 演示录屏视频
  BUILD-WINDOWS.md      ← 打包详细说明（Markdown）
  NOTICE.md             ← 第三方资源与模型授权说明
  README.md             ← 项目总览
